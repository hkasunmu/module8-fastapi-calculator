MODULE 8 — FAST START FOR WINDOWS
=================================
1. Extract the ZIP file and open the extracted folder in VS Code.
2. Double-click 1_SETUP_WINDOWS.bat (or use the VS Code terminal: py -m pip install -r requirements.txt, then py -m playwright install chromium).
3. Double-click 2_START_APP_WINDOWS.bat (or run: py -m uvicorn main:app --reload).
4. Open http://127.0.0.1:8000 and calculate 12 + 3 = 15; take a screenshot of the browser showing 15.
5. Double-click 3_RUN_TESTS_WINDOWS.bat (or run py -m pytest -v). Tests should all pass.
6. Push THIS ENTIRE FOLDER to your own GitHub repository. Make sure .github/workflows/tests.yml is included.
7. On GitHub: Actions > FastAPI Calculator Tests > most recent successful run. Take a screenshot of green successful workflow.
8. Submit GitHub URL and both screenshots to Canvas.

IMPORTANT: Your professor said to use a provided FastAPI starter application. This is a standalone implementation of the rubric. If your instructor specifically requires modifying their starter files, compare it before submission.
